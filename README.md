# 3Dsiege

Compatibility / patch layer for **Combat Extended** + **IsoRim (Waylith / IsoRimZ)** on RimWorld 1.7 Unstable.

## Goal
Make CE combat systems work correctly with IsoRim multi-floor / 3D mapping (cross-layer LOS, height, pathing, cover) without forking CE or IsoRim when a patch+extension approach is enough.

## Scope (initial)
- Spike notes from live 1.7 + CE + IsoRimZ sessions
- Harmony/XML patches and thin C# glue as needed
- Acceptance via in-game DevMode / RimBridge, not pure unit tests
